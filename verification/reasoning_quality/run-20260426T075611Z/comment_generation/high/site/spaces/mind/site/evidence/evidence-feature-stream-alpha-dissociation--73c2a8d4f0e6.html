Feature Stream Alpha Dissociation

Evidence Excerpt

Independent components analysis isolated alpha-reactive components during the preparatory cue-target interval. Dorsal visual stream sources showed increased alpha power when motion was irrelevant, whereas ventral stream sources showed increased alpha power when color was irrelevant; component source distributions for the two feature sensitivities were significantly different.

Page references: Figure 3, pp.5-6

Type: figure_result

This evidence extends alpha suppression beyond spatial orienting. Because color and motion have different cortical processing streams, alpha increases in the stream tied to the irrelevant feature support a feature-selective gating account. The finding depends on ICA source estimation and is therefore best interpreted as source-localized EEG evidence rather than direct cortical recording.
