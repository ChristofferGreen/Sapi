    Temporal reuse is limited by whether cached frame data still corresponds to the same visible surface point. Reverse reprojection tests previous-frame positions and depth or identity agreement, while forward reprojection maps cached pixels into the target frame but must handle motion vectors, scattering, occlusion, and holes.

  • GPU-Centered Representations for Interactive ScaleMay 05, 2026TopicEvidence: 0Claims: 8Authors: Daniel Scherzer, Lei Yang, Oliver Mattausch, ...

    The sources repeatedly use GPU-compatible representations to preserve interactivity under scale: shader programs map spatial data to pixels, temporal techniques reuse frame-buffer information, crowd rendering compresses impostor textures, and graph visualization uses OpenGL accumulation fields or CUDA image-space transforms.

  • Temporal and Perceptual Quality Allocation in Real-Time RenderingMay 05, 2026TopicEvidence: 0Claims: 9Authors: Daniel Scherzer, Lei Yang, Oliver Mattausch, ...

    Real-time rendering systems can reduce cost by exploiting coherence across adjacent frames or across the human visual field instead of recomputing uniform full-quality results everywhere. Temporal coherence reuses previous-frame information when values remain stable, while foveated rendering allocates higher quality near the fovea and lower quality in the periphery under perceptual constraints.

    Temporal Coherence Methods in Real-Time Rendering surveys how adjacent interactive frames can reuse rendering work through reprojection, cache validation, refresh, and amortized sampling. It treats temporal coherence as a broad design principle for shader acceleration, anti-aliasing, shadows, global illumination, upsampling, frame interpolation, LOD, streaming, visibility culling, and perceptual effects.

  • Sample Quality and Perceptual Quality AllocationMay 05, 2026TopicEvidence: 0Claims: 7Authors: Benedikt Bitterli, Chris Wyman, Matt Pharr, ...

    Several sources treat real-time rendering as a problem of spending limited computation where it matters most. ReSTIR improves many-light direct illumination by raising direct-light sample quality before denoising, while foveated rendering allocates high quality to the foveal region and lower quality to the periphery.

  • Spatiotemporal Reuse for Real-Time RenderingMay 05, 2026TopicEvidence: 0Claims: 9Authors: Benedikt Bitterli, Chris Wyman, Matt Pharr, ...

    Frame-to-frame and neighborhood reuse appears as a shared acceleration strategy: ReSTIR reuses selected direct-light samples across spatial neighbors and prior frames, while temporal-coherence methods reuse intermediate or final shading information across adjacent frames.

  • Model-Driven Real-Time Rendering TradeoffsMay 05, 2026TopicEvidence: 0Claims: 8Authors: Gyorgy Denes, Akshay Jindal, Aliaksei Mikhailiuk, ...

    A concept page could compare rendering systems that use explicit models to choose practical approximations under real-time constraints. The motion-quality work uses a fitted perceptual model for refresh-rate and resolution selection; ReSTIR uses reservoir sampling and biased or unbiased estimators to trade variance, cost, and correctness; foveated rendering uses perceptual models and taxonomies to organize quality allocation across rendering paradigms.

  • Perceptual Quality Allocation Under Rendering BudgetsMay 05, 2026TopicEvidence: 0Claims: 7Authors: Gyorgy Denes, Akshay Jindal, Aliaksei Mikhailiuk, ...

    A concept page could synthesize methods that spend rendering work where viewers are most sensitive. The motion-quality model allocates resolution and refresh rate using spatial resolution, refresh rate, velocity, predictability, blur, and judder; foveated rendering allocates spatial quality using visual-acuity and contrast-sensitivity limits in the human visual system.

  • Temporal Stability, Artifacts, and Frame-to-Frame ReuseMay 05, 2026TopicEvidence: 0Claims: 8Authors: Gyorgy Denes, Akshay Jindal, Aliaksei Mikhailiuk, ...

    A concept page could connect perceptual motion artifacts with the technical limits of reusing frame data.
