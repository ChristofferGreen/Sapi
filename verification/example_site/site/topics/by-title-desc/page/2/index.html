  • Entanglement as both resource and bottleneckApr 26, 2026TopicEvidence: 0Claims: 7Authors: John Preskill, Frank Arute, Kunal Arya, ...

    This topic treats entanglement as the common resource behind quantum advantage claims, many-body NISQ exploration, random-circuit hardness, and quantum-network protocols, while also noting that entanglement makes control, verification, and scaling difficult. The NISQ source identifies highly entangled quantum dynamics as a natural arena for meaningful quantum advantage and describes noisy devices as experimental tools for exploring many-body quantum physics. The Sycamore source uses random circuits to create hard-to-simulate 53-qubit quantum states. The quantum-internet source shifts the same resource from one processor to distributed nodes and channels.

  • Compiler Optimization as Evidence-Driven Decision MakingApr 26, 2026TopicEvidence: 0Claims: 10Authors: Pohua P. Chang, Scott A. Mahlke, Wen-mei W. Hwu, ...

    The sources collectively support a topic about compilers as decision systems that use evidence about programs, executions, hardware, or timing models to select transformations. Machine-learning compilation uses empirical training data and program features to predict optimization choices, profile-guided optimization uses runtime counts to select hot super-block regions, and WCC uses static analyzer output to choose WCET-reducing transformations.

  • Coherent interfaces for scaling quantum systemsApr 26, 2026TopicEvidence: 0Claims: 8Authors: John Preskill, Frank Arute, Kunal Arya, ...

    This topic synthesizes the hardware-facing requirement shared by quantum computing and quantum networking sources: useful scaling depends not only on more qubits, but on preserving coherence while operations, measurements, and interfaces become larger and more complex. In the NISQ and Sycamore sources this pressure appears as two-qubit gate errors, readout errors, circuit depth, and predicted fidelity. In the quantum-internet source it appears as the need for reversible interconnects that convert quantum states between matter and light while preserving coherence and entanglement.
