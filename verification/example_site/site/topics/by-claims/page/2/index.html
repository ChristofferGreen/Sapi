  • Visual control tradeoffs in computed graphicsApr 26, 2026TopicEvidence: 0Claims: 7Authors: Ozan Ersoy, Christophe Hurter, Fernando V Paulovich, ...

Skeleton-based edge bundling lets users tune smoothing, relaxation, and cushion shading, but the same method is limited because bundling overdraws individual edges and distorts directions. Crowd rendering similarly uses PCA-informed impostor planes to reduce popping, alpha-channel multipass recoloring to add variation, and shadow projection to preserve posture cues, all within an impostor-based approximation.
