Disconnection Complex Results

Evidence Excerpt

A split-brain-like model begins with a large main complex obtained by connecting two thalamocortical-like subsets through reciprocal “callosum-like” connections plus a “subcortical” common input; the main complex has high Φ (Φ = 72 bits). If the “callosum-like” connections are removed, the main complex breaks down into two smaller complexes, each of which still has a high value of Φ (Φ = 61 bits). In a functional-disconnection model, if the “auditory” module is functionally disconnected, the main complex includes just the “supramodal” and “visual” modules and Φ is only minimally reduced (Φ = 57 bits).

These model results show how the theory handles split consciousness and selective loss of content. A structural disconnection can divide one conscious complex into two, while functional disconnection can exclude a module from the main complex without abolishing all consciousness. The result supports the claim that conscious level and content depend on the current integration structure, not anatomical presence alone.
