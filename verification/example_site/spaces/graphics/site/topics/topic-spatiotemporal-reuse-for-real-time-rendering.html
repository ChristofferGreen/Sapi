Spatiotemporal Reuse for Real-Time Rendering

Structure: wiki

Comparison scope

This topic can compare reservoir combination, reverse and forward reprojection, amortized sampling, cache refresh, and the limits imposed by holes, stale values, and discontinuities.

Reuse constraints

The shared constraint is that reuse works best when spatial or temporal correlation is strong. Disocclusions, fast changes, unstable shading, and accumulated resampling error require validation, refresh, reshading, or fallback computation.

Shared reuse strategy

Frame-to-frame and neighborhood reuse appears as a shared acceleration strategy: ReSTIR reuses selected direct-light samples across spatial neighbors and prior frames, while temporal-coherence methods reuse intermediate or final shading information across adjacent frames.

Claims Used by This Topic

  • Refresh controls cache staleness

    Cached temporal data must be refreshed because reused values become stale through shading changes and resampling error, so refresh strategies trade coherence, noise, discontinuities, and GPU branch costs.

  • Disocclusion requires hole filling

    Disoccluded regions constrain temporal reuse because previous-frame data may be absent; practical systems must reshade these regions or fill holes approximately.

  • Forward reprojection trades geometry

    Forward reprojection can map cached pixels directly into the target frame without processing current scene geometry, but it depends on motion vectors and must address scattering, occlusion, and holes.

  • Frames preserve visible points

    Real-time rendering sequences exhibit substantial spatio-temporal coherence, and game-like scenes often keep more than 90 percent of visible surface points visible from one frame to the next.

  • Reservoirs amplify candidate counts

    Reservoir sampling makes spatiotemporal reuse practical because a pixel can combine selected samples and weight sums from neighboring reservoirs without storing each candidate stream.

  • ReSTIR reuses light candidates

    ReSTIR samples one-bounce direct lighting by repeatedly resampling light candidates and reusing useful samples across spatial neighbors and prior frames.

  • Reverse reprojection validates reuse

    Reverse reprojection caching validates reuse by mapping a current pixel to its previous-frame position and accepting the cached value only when depth or identity tests indicate the same surface point.

  • Coherence amortizes shading work

    Temporal coherence can reduce rendering cost by reusing intermediate or final shading information from previous frames instead of recomputing every frame from scratch.
