Image-space geometric abstraction for readable visual complexity

Structure: wiki

Readable but partial representations

The shared concept is not merely acceleration: abstraction changes what the viewer can read. Edge bundling sacrifices individual edge identity and direction fidelity to expose coarse connectivity, while crowd impostors trade full per-avatar geometry for scalable visual presence. Shader raymarching provides a related but weaker bridge because it also treats geometry through mathematical spatial descriptions, marching rays through distance fields inside a fragment shader.

Shared abstraction strategy

Across the edge-bundling and crowd-rendering sources, dense visual scenes become manageable by replacing raw geometric complexity with structured image-space or sample-based abstractions. Skeleton-based edge bundling clusters geometrically similar edges, inflates cluster shapes, extracts skeletons, and attracts edges toward locally centered targets; image-based crowd rendering uses impostor samples, positional and directional discretization, and optimized texture storage to display large animated crowds at interactive rates.

Claims Used by This Topic

  • Skeletons guide edge bundles

    Skeletons of inflated edge-cluster shapes provide locally centered targets for bundling geometrically similar graph edges.

  • Sampling clusters similar edges

    Hierarchical agglomerative clustering with full linkage and Euclidean distances between uniformly sampled edge points yields clusters of geometrically close edges that follow graph structure.

  • Attraction preserves node endpoints

    The attraction rule moves interior edge points toward feature-transform locations on the skeleton while keeping edge endpoints fixed at their node positions.

  • Path regularization prevents kinks

    Restricting attraction to skeleton paths passing through endpoint feature points prevents sharp kinks caused by feature-transform singularities.

  • Iterative reclustering coarsens bundles

    Repeated reclustering with decreasing similarity thresholds creates bottom-up bundling in which fine local bundles merge into coarser structures.

  • Bundling trades detail for structure

    Skeleton-based edge bundling is most appropriate for coarse-scale connectivity exploration because bundling overdraws individual edges and distorts edge directions.

  • Impostors enable real-time crowds

    Image-based impostor rendering with positional and directional discretization can display dense animated crowds in large virtual urban environments at interactive rates.

  • Sample packing cuts memory

    Packing each prerendered human sample into the smallest containing rectangle reduces the texture memory needed for human images to one quarter of the original value without loss of image quality.

  • Raymarching recreates shader depth

    Raymarching can recreate three-dimensional depth inside a fragment shader by marching a ray through a distance-field description until it reaches an object.
