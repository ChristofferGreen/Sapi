Path-Based Singularity Regularization

Evidence Excerpt

For each edge, the algorithm selects a skeleton path passing through the feature points of both edge endpoints. If a point's FT_S(x) is not on that path, the point is treated as special and mapped to a corresponding point on the path by arc-length interpolation before the attraction formula is applied.

Page references: Sec. 2.4.1, Fig. 3

Type: formal_argument

This procedural evidence explains how the method avoids discontinuities that would otherwise create sharp kinks when edges cross Voronoi-like feature-transform boundaries. It supports the robustness claim for smooth bundles, while depending on correctly detected skeleton tips and paths.
