LaGO Interaction Controls

Evidence Excerpt

LaGO provides zoom and pan operations to support the interactive exploration of visualized graphs. Similar to related density based approaches the bandwidth parameter h is bound to the viewport to support semantic zooming. The interactive exploration leads to large variations of the visualized density values and fixed color mapping cannot address sparse and crowded viewports equally. We therefore provide an automatic normalization of the densities with the maximal value of the current viewport. LaGO therefore provides a detail on demand implementation that allows the interactive labeling of the node density field.

Page references: p.2492

Type: observational_result

This evidence connects the rendering method to an exploratory software workflow. It shows that the implementation is not only a batch renderer: zooming, panning, bandwidth adjustment, normalization, color mapping, and label retrieval are treated as part of the graph-analysis interface. The evidence is descriptive rather than a controlled user-study result.
