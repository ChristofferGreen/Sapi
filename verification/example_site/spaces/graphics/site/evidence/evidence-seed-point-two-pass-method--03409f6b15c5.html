Two-Pass Seed Points

Evidence Excerpt

For large node sets, however, the described method is time inefficient because the amount of textured rectangles depends linearly on the number of nodes within the screen area. Therefore, we extend the method and significantly reduce rendering time by binning nearby node coordinates into pixels. Instead of rasterizing multiple rectangles at the same position, a single weighted rasterization step per bin is then sufficient to create the same density field. Therefore we propose the Seed Point Method, a technique that uses two render-passes: one to merge the nodes in their pixel-sized bins and one to create the actual density field.

Page references: p.2488, Fig.2

Type: formal_argument

This passage supplies the mechanism behind the node aggregation claim. It identifies the original cost driver, explains pixel binning as a mathematically equivalent density-field shortcut for a viewport, and describes the two-pass rendering structure. The evidence supports speed and storage claims but does not by itself prove user-facing readability or superiority over every possible spatial hierarchy.
