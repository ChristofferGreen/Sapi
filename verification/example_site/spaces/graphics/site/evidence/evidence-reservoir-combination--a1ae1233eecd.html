Reservoir Combination Argument

Evidence Excerpt

The algorithm treats each reservoir's selected sample as a fresh sample with weight equal to the accumulated weight sum, producing a result equivalent to sampling over the combined input streams while requiring only reservoir state access.

Page references: Sec. 3.2, Alg. 4

Type: formal_argument

This formal algorithmic observation explains why ReSTIR can reuse candidates across pixels and frames without storing every candidate. It establishes the core mechanism behind the method's low memory footprint and effective candidate-count amplification.
