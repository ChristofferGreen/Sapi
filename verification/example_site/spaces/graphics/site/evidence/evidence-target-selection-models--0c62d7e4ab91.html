Reuse Target Selection Models

Evidence Excerpt

The semi-automatic target identification method analyzes shader source code, renders training sequences, gathers error and performance data, models expected reuse error as e_hat(f_m,n) = alpha_m(1 - exp(-lambda_m(n-1))), and models pixel rendering cost from measured cache-hit and cache-miss times. The system then selects the shader component with the greatest performance improvement below a target error threshold.

Page references: pp.2385-2386, Eq.4, Eq.5, Eq.6, Fig.7, Fig.8

Type: model_constraint

This evidence grounds the claim that temporal reuse target selection is a measurable optimization problem, not a fixed recipe. The method links expected input variation, refresh period, error tolerance, and rendering cost, showing why expensive and stable intermediate computations are best suited for reuse.
