Sampled Edge Distance

Evidence Excerpt

The clustering section defines d(e_i,e_j)=sqrt(sum_{k=1..N} ||e_ik-e_jk||^2) over uniformly spaced edge samples, with N in [50,100], and reports that hierarchical bottom-up agglomerative clustering with full linkage and this Euclidean distance gives the best results.

Page references: Eq. 1, Sec. 2.1

Type: equation

This equation-level evidence explains how the method obtains elongated, coherent edge groups before skeletonization. Because the metric compares full sampled trajectories rather than only endpoints, it supports bundling curved or spatially similar edges, but it also means cluster quality depends on the initial layout and sampling resolution.

  • Iterative reclustering coarsens bundles
