Reverse Cache Hit Test

Evidence Excerpt

The reverse reprojection cache stores pixel data f_t and a screen-space depth buffer d_t. For a current pixel p, the reprojection operator pi_t-1(p) maps the generating scene point to its previous-frame position. If the reprojected depth equals the stored previous depth within tolerance, the cached value can be reused; otherwise pi_t-1(p) is treated as empty, a cache miss.

Page references: pp.2381-2382, Fig.3

Type: formal_argument

This formal argument establishes the correctness guard behind reverse reprojection. Reuse is not merely copying an old pixel; it is conditioned on recovering the same surface point in the previous frame. The depth comparison also explains why disocclusions, object motion, and visibility changes become explicit cache misses.
