Quasi-Memory Dilemma Response

Evidence Excerpt

R.B.’s recollections provide an existence proof for a kind of memory that navigates between the horns of Schechtman’s dilemma. In R.B., the ‘mineness’ of episodic recollection is separated from the content. The notion of quasi-memory is supposed to undergird a theory of personal identity, but which (if any) of these self-representations is required in order for a candidate quasi-memory to count as being ‘caused in the normal way’ ?

Page references: pp.694-695

Type: formal_argument

This formal-philosophical evidence links the neurological case to the quasi-memory debate. R.B. is used to challenge the claim that apparent memory must either be delusional or presuppose identity, while also forcing quasi-memory theorists to define which self-representation matters.
