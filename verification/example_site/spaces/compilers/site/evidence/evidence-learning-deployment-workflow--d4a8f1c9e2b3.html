Learning and Deployment Workflow

Evidence Excerpt

There are two main stages involved: learning and deployment. The first stage learns the model based on training data, while the second uses the model on new unseen programs. Within the learning stage, we needs a way of representing programs in a systematic way. This representation is known as the program features.

Page references: p.2

Type: formal_argument

This workflow fragment establishes the source’s central mechanism: compiler optimization decisions are not hand-coded as fixed heuristics alone, but are learned from training examples and then deployed on new programs. It supports the broad claims about feature engineering, training data, and compiler-integrated prediction, while remaining scoped to optimization decisions rather than compiler correctness or transformation legality.
