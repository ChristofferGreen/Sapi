bzip2 resubstitution rank table

Evidence Excerpt

Table 5 lists the rank of each bzip2 resubstitution binary for Itanium and Itanium2, along with the percent slower than the rank-1 FDO binary. The text explains that an effective FDO system should give low ranks to resubstitution binaries, but the ranks are fairly evenly distributed across the possible range, suggesting no relationship between feedback-information quality and resulting binary performance.

Page references: Table 5

Type: table_result

Resubstitution should be a favorable case because the profiling input and evaluation input are identical. The table's mixed rankings therefore weaken the assumption that more exact feedback automatically yields the best binary in this ORC configuration. The result is a limitation of the compiler system studied, not a universal proof that resubstitution is useless.
