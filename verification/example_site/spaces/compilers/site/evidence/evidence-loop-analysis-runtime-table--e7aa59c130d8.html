Evidence Excerpt

Table 2 gives loop-analysis run times: matmul is 8.4 s basic, 2.4 s with slicing, and 0.8 s with polytope evaluation; fft is 920.7 s basic, 119.7 s with slicing, and 110.5 s with polytope evaluation; matrix1 is 0.8 s, 0.09 s, and 0.03 s respectively.

Page references: Table 2, pp.271-272

Type: table_result

These measured timings show that the auxiliary loop-analysis techniques address scalability, not merely precision. The examples also reveal scope limits: polyhedral evaluation helps when its prerequisites apply, while other benchmarks may fall back to the iterative analysis.
