Expanded SPEC input workload

Evidence Excerpt

The workload selection section uses SPEC CINT2000 benchmarks and datasets, includes the SPEC test, train, and ref inputs, and adds inputs selected to represent typical benchmark workloads. It reports that inputs for bzip2 and gzip are selected as files in common formats, parser uses Project Gutenberg, web-page, and Reuters inputs, and in total 116 inputs are used, of which only 32 are provided by SPEC.

Page references: Section 2.3

Type: measurement

The expanded workload is critical to the paper's interpretation because it tests whether conclusions based on the small standard SPEC input sets generalize. The evidence shows that Aestimo deliberately stresses training and evaluation input sensitivity across a broader workload, making the reported variations harder to dismiss as artifacts of a tiny benchmark input set.
