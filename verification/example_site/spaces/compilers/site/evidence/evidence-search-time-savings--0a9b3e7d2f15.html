AutoTVM Matching Time Table

Evidence Excerpt

Table 3 lists measurements and wall-clock time for Ansor to match AutoTVM on Intel CPU at batch size 1: ResNet-50 uses 21,220 AutoTVM measurements versus 6,403 Ansor measurements, MobileNet-V2 uses 31,272 versus 1,892, DCGAN uses 3,003 versus 298, and BERT uses 6,220 versus 496. Wall-clock examples include 39,250 seconds versus 4,540 for ResNet-50 and 58,468 seconds versus 660 for MobileNet-V2.

Page references: Table 3, Section 7.4

Type: table_result

This table is concrete evidence for the search-efficiency claim. It separates measurement count from wall-clock time, showing that the advantage is not only a benchmarking artifact. The paper attributes the savings to the task scheduler, fine-tuning, and broader coverage of useful optimizations; the evidence is specific to matching AutoTVM on the Intel CPU network benchmark.
