Remote CNOT Bell-State Protocol

Evidence Excerpt

Remote CNOT. To perform a CNOT between remote physical qubits stored at different processors, a Bell state such as Phi+ must be distributed through the quantum link so that each pair member is stored within a communication qubit at each processor. Once the Bell state is available, the remote CNOT is obtained with a local CNOT between the data and the communication qubit at each processor, followed by a conditional gate on the data qubit depending on the measurement of the remote communication qubit.

This figure-level construction is the operational foundation for the compiler problem. It establishes why distributed gates require communication qubits, Bell-state generation, local gates, measurement, and classical feed-forward, so remote CNOTs are not interchangeable with local CNOTs in cost or scheduling.
