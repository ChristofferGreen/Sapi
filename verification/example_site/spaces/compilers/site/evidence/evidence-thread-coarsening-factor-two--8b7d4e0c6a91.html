Thread Coarsening Example

Evidence Excerpt

Fig. 2: An OpenCL thread coarsening example reproduced from [15]. The original OpenCL code is shown at (a) where each thread takes the square of one element of the input array. When coarsened by a factor of two (b), each thread now processes two elements of the input array.

Page references: Fig. 2, p.3

Type: figure_result

The figure makes the optimization target concrete by showing how thread coarsening changes the mapping between GPU work-items and threads. Because the transformation has both potential benefits and costs, this artifact grounds the claim that a learned model can be useful for selecting when and how strongly to coarsen rather than applying a universal rule.
