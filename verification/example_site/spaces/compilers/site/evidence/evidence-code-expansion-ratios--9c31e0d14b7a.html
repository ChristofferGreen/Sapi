Code Expansion Ratios

Evidence Excerpt

For these experiments the authors use an execution count threshold of 100 before adding basic blocks to a trace. Table 6 reports profile-based executable size ratios relative to globally optimized programs: cccp 1.03, cmp 1.11, compress 1.01, eqn 1.10, eqntott 1.00, espresso 1.07, grep 1.09, lex 1.08, mpla 1.13, tbl 1.06, wc 1.01, xlisp 1.20, yacc 1.09, with average 1.07.

Page references: Table 6, p.43

Type: table_result

This evidence addresses the main cost risk of super-block formation: tail duplication can increase code size. The reported threshold and size ratios show a deliberate control mechanism and quantify the remaining expansion. The worst listed case is larger than average, so the result supports controlled rather than zero-cost growth.
