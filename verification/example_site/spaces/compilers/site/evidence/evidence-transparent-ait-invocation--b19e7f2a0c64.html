Transparent aiT Invocation

Evidence Excerpt

WCC produces a CRL2 file for the program requiring WCET timing data, invokes aiT fully transparently, and performs value, loop bound, cache, pipeline, and path analysis. The compiler user is described as unaware that timing analysis is performed in the background.

Page references: Sect. 3.3, p.261

Type: formal_argument

This passage is concrete process evidence for the compiler-analyzer integration. It shows that timing analysis is not a detached manual step; it is embedded in the compiler workflow and supplies the WCET data used by later optimization decisions.
