Cost Model Accuracy Metrics

Evidence Excerpt

The cost-model evaluation uses 25,000 programs measured while tuning ResNet-50 on Intel CPU, randomly selecting 20,000 programs for training and 5,000 for testing. The model achieves 0.079 RMSE, 0.958 R2 correlation, 0.851 pairwise comparison accuracy, and 0.624 recall@30 for top-30 programs on the test set.

Page references: Figure 11, Section 7.5

Type: statistical_result

This evidence supports the cost-model claim with explicit dataset size and evaluation metrics. The model need not perfectly predict absolute throughput; the relevant evidence is that it can rank and identify promising programs well enough to guide evolutionary search. The scope is narrower than the whole system because the reported metrics are for one ResNet-50 tuning dataset on Intel CPU.
