Gradient-Based Task Allocation

Evidence Excerpt

The task scheduler formulates tuning as minimizing an end-to-end cost function over subgraph latencies, approximates the gradient for each task, and allocates the next resource unit to the task with the largest absolute gradient. The text explains that Ansor initially favors high-latency subgraphs, then moves away when continued tuning stops reducing latency.

Page references: Section 6.1, Section 6.2

Type: equation

This is evidence for the scheduler claim because it gives the mechanism, not just the outcome. The scheduler treats tuning time as a resource allocation problem across many subgraphs and uses observed improvement history to focus on bottlenecks. The scope is strongest for workloads partitioned into repeated or similar static subgraphs, where latency improvements can be observed and compared.
