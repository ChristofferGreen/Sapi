Five-run workload evaluation

Evidence Excerpt

After the compilation process, Aestimo executes each FDO binary on each input of the program workload five times. It then analyzes program run times and optimization logs, calculating difference and alignment metrics. It reports arithmetic mean runtime improvement over the static binary and a geometric sum that normalizes each runtime against the corresponding static runtime before aggregation.

Page references: Section 2.2

Type: measurement

This evidence grounds the performance side of the tool. Aestimo is not only comparing compiler logs; it runs each generated binary across the whole workload and aggregates the results against a static baseline. The five-trial design and two aggregation methods give stronger evidence than a single run, although the paper still observes large trial-to-trial ranges in some figures.
