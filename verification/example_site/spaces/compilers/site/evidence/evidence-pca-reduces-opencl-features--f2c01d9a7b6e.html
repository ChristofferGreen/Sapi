OpenCL Feature Reduction

Evidence Excerpt

They started from 17 candidate features. These include things like the number of and types of instructions and memory level parallelism (MLP) within an OpenCL kernel. Table I gives the list of candidate features used in [15]. ... Principal Component Analysis ... is applied to map the 17 candidate features into 7 aggregated features, so that each aggregated feature is a linear combination of the original features.

Page references: Table I, pp.3-4

Type: model_constraint

This passage provides a concrete instance of feature engineering in compiler learning: static LLVM-derived code features are chosen for OpenCL kernels and then compressed with PCA. It supports the claim that feature dimensionality is not a cosmetic concern; it affects the amount of data needed and the model’s ability to ignore redundant program descriptions.
