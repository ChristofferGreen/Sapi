Table 2 lists super-block code optimizations: constant propagation, copy propagation, constant combining, common subexpression elimination, redundant store elimination, redundant load elimination, dead code removal, loop invariant code removal, loop induction variable elimination, and global variable migration. The non-loop based code optimizations work on a single super-block at a time. The loop based code optimizations work on a single super-block loop at a time.
