bzip2 training-performance spread

Evidence Excerpt

The bzip2 case study states that, despite large runtime ranges between trials, training on the combined input results in performance gains of about 8%, while training on xml improves performance by only 2%. In the best-case comparison, performance on Itanium has a minimum improvement of about 4% and a maximum gain of about 13%, and the fastest training input differs across evaluation inputs.

Page references: Figures 8-9

Type: figure_result

This figure-derived evidence ties decision sensitivity to user-visible runtime outcomes. It shows that input selection changes measured performance enough to alter conclusions about an optimization. The evidence also motivates the paper's warning against single-input evaluation because different evaluation inputs can favor different trained binaries.
