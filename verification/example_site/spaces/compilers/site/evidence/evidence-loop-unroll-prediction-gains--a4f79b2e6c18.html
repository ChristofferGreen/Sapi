Loop Unroll Prediction Gains

Evidence Excerpt

They used over 2,500 loops from 72 benchmarks to train two machine learning models (a nearest neighbor and a support vector machines model) to predict the loop unroll factor for unseen loops. Using a richer set of features than [14], their techniques correctly predict the unroll factor for 65% of the testing loops, leading to on average, a 5% improvement for the SPEC 2000 benchmark suite.

Page references: p.6

Type: statistical_result

The loop-unrolling result is a quantitative benchmark for direct prediction. It does not prove that all compiler choices are easy to learn, but it demonstrates that for a bounded option set, feature-based supervised models can predict useful decisions and produce measurable application-level performance improvements.
