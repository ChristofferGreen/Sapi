Compositional Compiler Infrastructure for Domain-Specific Objectives

Structure: wiki

Classical and learned compiler pipelines

Profile-guided classic optimization is explicitly complementary to conventional optimization, reformulating classic scalar transformations for super-blocks and super-block loops. Machine-learning compilation similarly inserts a learned model into the compiler after offline training, making optimization decisions for new programs rather than replacing the rest of the compiler pipeline.

Domain-specific objectives

The sources target different objectives: average speed, learned heuristic selection, worst-case execution time, and distributed quantum feasibility or depth. A synthesis page can use this contrast to explain how modern compiler frameworks embed domain-specific evidence and passes while preserving a broader compiler workflow.

Shared concept

Across the sources, compiler improvements are presented as integrated infrastructures rather than isolated transformations. Profile-guided optimization adds profiling, super-block formation, and profile-aware versions of classic optimizations; machine-learning compilation adds training and deployment stages around the compiler; WCC connects a C compiler to aiT and composes multiple WCET-aware optimizations; distributed quantum compilation maps algorithms to constrained distributed architectures through strategy-specific compilation of remote operations.

WCET-aware composition

WCC provides a strong infrastructure example because it couples static analysis to compilation, raises timing facts back to source-level structures, accelerates loop analysis through slicing and polyhedral evaluation, and composes register allocation, code scratchpad allocation, data scratchpad allocation, and procedure positioning. The matmult case shows these optimizations can combine into a much larger WCET reduction than an isolated pass would suggest.

Claims Used by This Topic

  • Classic optimizations fit super-blocks

    Classic scalar optimizations can be reformulated to operate on super-blocks and super-block loops rather than only on traditional basic blocks or whole loops.

  • Constrained choices enable direct prediction

    Direct prediction of the best compiler option is practical for relatively small optimization problems and has produced measurable gains in loop unrolling and thread-coarsening studies.

  • Distributed architectures require compilers

    Distributed quantum computing requires compilers that can map arbitrary quantum algorithms to distributed architectures while accounting for network and communication constraints.

  • Slicing accelerates loop analysis

    Interprocedural slicing and polyhedral loop evaluation substantially reduce loop-analysis time for many benchmarks while preserving safe loop-bound analysis.

  • Profile optimizations complement convention

    Profile-based classic optimizations are intended to complement conventional optimizations rather than replace them.

  • Implementation cost is modest

    The implementation cost of profile-based classic optimization was modest relative to the existing global optimizer.

  • Training precedes deployment

    The machine-learning compiler workflow separates model learning from deployment: training data is used to learn a model, and the learned model is then inserted into the compiler to make predictions for new programs.

  • Compiler complexity is polynomial

    The proposed compiler is computationally efficient because distributing a circuit has O(d n squared) complexity, with d the circuit depth and n the number of QPUs or logical qubits in the modeled worst case.

  • Optimizations compose strongly

    The WCC optimizations compose: applying register allocation, code and data scratchpad allocation, and procedure positioning to matmult reduces WCET by more than 70 percent relative to WCC -O2.

  • WCC integrates static analysis

    WCC couples a C compiler to the aiT static WCET analyzer so that WCET data is produced transparently during compilation rather than by a separate manual post-compilation step.
