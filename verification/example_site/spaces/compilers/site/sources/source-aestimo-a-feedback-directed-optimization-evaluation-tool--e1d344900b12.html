Overview and Commentary

Aestimo evaluates how training input selection affects feedback-directed optimization decisions and performance. It isolates individual transformations, compares optimization logs with difference and alignment metrics, and uses ORC/SPEC CINT2000 experiments, especially bzip2, to show why single-input FDO evaluation can mislead.

Core Argument

Section 02

Isolation Method

Aestimo's strongest design choice is its forced-decision recompilation flow. It logs the decisions made for one profile-guided optimization, then recompiles so that only that optimization uses the logged profile-derived choices. This does not eliminate all optimization interactions, but it gives a practical way to estimate the contribution and sensitivity of individual transformations such as inlining and if-conversion.

Section 04

Workload Breadth

The study expands beyond the standard SPEC input sets by adding files and datasets meant to represent typical uses of the benchmark programs. This matters because the paper's conclusions depend on seeing variation that the small default benchmark inputs could hide. The 116-input workload, with only 32 SPEC-provided inputs, makes the experiment more relevant to real FDO deployment scenarios.
