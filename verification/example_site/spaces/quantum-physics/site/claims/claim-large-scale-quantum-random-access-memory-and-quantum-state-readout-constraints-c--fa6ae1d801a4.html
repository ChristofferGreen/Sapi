Input output bottlenecks dominate

Claim Statement

Large-scale quantum random access memory and quantum-state readout constraints can erase practical advantages for many linear-algebra-based quantum machine learning algorithms on classical data.

Primary source: Quantum Machine Learning Speedups and Bottlenecks

Pages Using This Claim

  • source Quantum Machine Learning Speedups and Bottlenecks

    This review frames quantum machine learning as the attempt to convert quantum algorithmic speedups into practical learning and data-analysis tools. Its central message is balanced: qBLAS, HHL, qPCA, quantum support vector machines, and quantum Boltzmann machines create plausible advantages, but input, output, costing, and benchmarking problems determine whether those advantages survive in complete systems.

Evidence Items

  • Quadratic Boltzmann Training Gains

    Quantum methods can make Boltzmann systems thermalize quadratically faster, reduce the samples needed to learn performance, and use quadratically fewer accesses to training data under qRAM or black-box access.

  • Four Practical Caveats

    The review names four fundamental problems for future work: input problem, output problem, costing problem, and benchmarking problem.

  • Input Output qRAM Bottleneck

    Applying HHL, least-squares fitting, qPCA, support vector machines, and related methods to classical data begins by loading large data sets into a quantum system, which can require exponential time without qRAM.

  • qPCA Density Matrix Route

    For qPCA, qRAM maps a data vector v_j into |v_j>; repeated sampling prepares rho proportional to the covariance matrix, and phase estimation maps |v> into principal-component and eigenvalue registers.
