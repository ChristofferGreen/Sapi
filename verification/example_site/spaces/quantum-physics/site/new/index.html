  • Hybrid Shallow Quantum Algorithms Under NISQ NoiseApr 26, 2026TopicAuthors: Alberto Peruzzo, Jarrod McClean, Peter Shadbolt, Man-Hong Yung, Xiao-Qi Zhou, Peter J. Love, Alán Aspuru-Guzik, Jeremy L. O’Brien, John Preskill

    Near-term quantum algorithms can be framed as hybrid workflows that keep coherent quantum circuits short while outsourcing parameter search and aggregation to classical computation. The photonic variational eigensolver illustrates this pattern by estimating Hamiltonian expectation values through repeated state preparations and Pauli measurements, then using a classical minimizer to improve the Rayleigh-Ritz quotient.
